## 🆘 TROUBLESHOOTING

### "Build Failed" Error

**Check**:
1. View build logs in platform dashboard
2. Common issue: Missing dependencies
3. **Fix**: Ensure `requirements.txt` and `package.json` are complete

### "Application Error" or 503

**Check**:
1. View application logs
2. Common issue: Missing environment variables
3. **Fix**: Add all required environment variables

### "Database Connection Failed"

**Check**:
1. Verify DATABASE_URL is set
2. Use "Internal" database URL (not external)
3. **Fix**: Copy the correct URL from database settings

### "CORS Error" in Browser

**Check**:
1. Verify NEXT_PUBLIC_API_URL points to backend
2. Check backend CORS settings
3. **Fix**: Update frontend environment variable

### "Cannot Reach API"

**Check**:
1. Backend service is running
2. Frontend has correct API URL
3. **Fix**: Update NEXT_PUBLIC_API_URL and redeploy frontend
